# Contributing

Contributions that improve AI literacy, complex B2B sales practice, AI roles, and organization transformation are welcome.

## Code contributions

1. Run `npm ci` and `npm run check`.
2. Keep changes focused and add tests for behavior changes.
3. Do not add production deployment, SSH, Nginx, DNS, server, CRM, or credential material.
4. By submitting a code contribution, you agree that it may be distributed under Apache-2.0.

## Knowledge-content contributions

1. Link the original source and identify its publisher and date.
2. Separate source facts from project analysis.
3. Use at least two independent factual supports for an industry-level conclusion.
4. Do not paste full articles, paywalled text, unlicensed images, personal data, or long quotations.
5. Mark AI-assisted drafts; AI output remains a candidate until the project owner approves it.
6. By submitting original content, you agree that it may be distributed under CC BY 4.0.

A candidate in a public Draft PR is publicly visible even when its website publication state is `not_published`. Removing a candidate from a PR does not make an already disclosed commit private.

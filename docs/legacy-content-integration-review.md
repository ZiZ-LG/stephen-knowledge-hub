## 1. 当前决定与审核边界

- 用户本次要求完整本地审核版，审核后才同步 GitHub 和部署。这替代了历史上“完整旧手册继续作为主入口、不被新路径改写”的决定。
- 新版只维护一套学习内容。`/learn/` 是学习地图，`/learn/knowledge-answers/` 是完整 RAG 课程入口；`/editorial-example/` 只保留兼容。
- 旧在线路径 `/fieldbook/` 只承担退役说明和新去向导航。原 HTML 已原字节归档到 `docs/archive/fieldbook/fieldbook-before-integration.html`，不再放回公共目录持续维护。
- 新课已由所有者批准。唯一构建开关在 `vite.config.ts`：`learningReleaseApproved=true`，仅对应本次八课与十四练习。先前审核版采用 `false`；其构建排除检查保留在第 9 节作为历史验证。后续新批次不能复用本次批准。
- 旧本机记录只读查看与原文导出，不覆盖、不删除、不换算为新课程完成。原八个工具 ID 保持不变。
- 本批不改变扫描频率、审核权限、发布或推送机制，不接触 CRM 数据或私有运维配置。日常运营仍为每天最多 30 分钟，不另加隐含复盘工时。

## 6. 现有工具与互链验收

八个工具保持原 ID：`company-role-research`、`transition-evidence`、`role-gap-analysis`、`discovery-interview`、`ai-maturity-scan`、`value-hypothesis-one-pager`、`poc-success-canvas`、`stakeholder-adoption-risk`。模板、已存材料和编辑能力继续使用 `src/content/tools.ts` 与 `src/pages/ToolsPage.tsx`，不建另一套旧手册工作台。

按实际页面核验下列路径，配置存在不等于交互已通过：

1. 已审行业内容或专题 → 解释原理的课程 → 合适的工具。
2. 课程 → 相关专题，区分稳定方法与有日期的行业事实。
3. 工具 → 对应课程与可选练习；保留当前材料，不自动覆盖为练习答案。
4. 搜索术语、正文中的概念或练习问题 → 相关课程，再进入其练习与工具。
5. `/fieldbook/` 及旧章节锚点 → 退役说明和新去向；不返回另一套旧教程。

相关实现为 `src/learning/access.ts`、`src/components/LearningLinks.tsx`、`src/pages/LessonPage.tsx`、`src/pages/RadarPage.tsx`。最终浏览器检查结果填写到第 9 节。
